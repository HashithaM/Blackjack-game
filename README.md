# Blackjack Game

A terminal-based Blackjack game written in Python. The player draws cards against a computer dealer, with Ace adjustment, Blackjack detection, bust handling, and score comparison.

## Features

- Random card dealing from a Blackjack-style deck
- Ace conversion from 11 to 1 when needed
- Natural Blackjack detection
- Dealer draws until reaching 17
- Replay loop for multiple rounds

## Run

```bash
python main.py
```

No third-party packages are required.

## Project files

- `main.py` — game rules and terminal interaction
- `art.py` — ASCII logo
